# 번들 데이터

## sigungu.csv — 시군구(LAWD_CD) 코드표

| 열 | 의미 |
|---|---|
| lawd_cd | 법정동코드 앞 5자리 (실거래가 API 의 `LAWD_CD`) |
| sido | 시도명 |
| sigungu | 시군구명 (구를 둔 시의 구는 `수원시 장안구` 형식, 세종은 빈 값) |
| parent_cd | 상위 시 코드 (구를 둔 시의 하위 구만) |
| is_leaf | 1 = 실거래 조회 단위, 0 = 하위 구로 펼쳐야 하는 시 |
| former_cd | 코드 변경 전 옛 코드 (있을 때만) |
| note | 변경 사유 |

출처: 행정안전부 법정동코드 (2022-09 스냅샷) + 이후 행정구역 변경 수동 반영
(강원·전북 특별자치도 코드 변경, 군위군 대구 편입, 부천시 일반구 설치).
자세한 내용과 최신화 방법은 `docs/ARCHITECTURE.md` §7.1 참고.
